WEBSITE DESA TETEAJI
====================

Isi folder:
- index.html : struktur dan konten website
- style.css  : tampilan, warna, layout, responsif HP/desktop
- script.js  : menu HP, tanggal otomatis, animasi angka, galeri, form demo

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder website_desa_teteaji.
3. Klik dua kali index.html, atau buka dengan browser.
4. Untuk mengedit, buka file dengan VS Code atau editor teks.

Yang perlu disesuaikan sebelum dipakai resmi:
- Nama desa, kabupaten, profil, visi-misi.
- Statistik penduduk dan wilayah (angka saat ini hanya contoh).
- Foto stok dengan foto asli desa.
- Berita contoh dan tanggal kegiatan.
- Kontak/alamat/kantor desa.
- Formulir saat ini hanya demo; belum mengirim pesan ke server.
- Foto eksternal memerlukan koneksi internet.

Dibuat dengan HTML, CSS, dan JavaScript murni.
